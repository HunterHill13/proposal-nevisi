## 1. تفکیک بنیادین دو سطح اعتبارسنجی (Bifurcated Validation Architecture)

در نسخه 8.3 معماری Proposal-Nevisi، تمایز قطعی و شفاف میان **Software Validation** (اعتبارسنجی نرم‌افزاری کد و داده‌ساختارها) و **Scientific Evidence Validation** (اعتبارسنجی تجربی و شواهد علمی مقالات) برقرار شده است:

| سطح ارزیابی | شاخص‌های مورد بررسی | وضعیت در نسخه 8.3 |
| :--- | :--- | :--- |
| **A. Software Validation** | پاس شدن تست‌های واحد، یکپارچگی، رگرسیون، عدم نشت متغیرها به کد (Anti-Leakage)، ساختار ۱۴ بخشی پروپوزال، قالب‌بندی DOCX با تایپوگرافی دبی و bidi XML | **۲۳۶ از ۲۳۶ تست پاس شد (100% PASS)** |
| **B. Scientific Evidence Validation** | تطابق ماهیت شیمیایی ماده، پلتفرم ویروسی، مدل سلولی، آزمون‌های کمی، ممیزی شکاف جستجو و عدم ادعای سینرژی بدون دیتای ترکیبی مستقیم | **تأیید شکاف پژوهشی تجربی (NO_DIRECT_STUDY_IDENTIFIED)** |

> [!IMPORTANT]
> **گزارش صادقانه شواهد علمی:** بر خلاف سیستم‌های هوش مصنوعی که ممکن است بر پایه مطالعات جداگانه مونوتراپی ادعای هم‌افزایی قطعی نمایند، سیستم Proposal-Nevisi v8.3 اثبات می‌کند که **هیچ مطالعه منتشرشده‌ای به صورت مستقیم اثر توأم لوپئول خالص و ویروس نیوکاسل را بر سلول‌های A549 بررسی نکرده است**. لذا هم‌افزایی در این پروپوزال صرفاً به عنوان یک **فرضیه پژوهشی تجربی (HYPOTHESIS_ONLY)** با پشتوانه شواهد آنالوگ ساختاری و ویروسی فرمول‌بندی شده است.

## 2. جدول شاخص‌های ۱۴ گانه ممیزی علمی (14 Scientific Evidence Metrics)

| ردیف | شاخص ممیزی (Metric) | مقدار عددی / وضعیت تجربی | مرجع و استاندارد ارزیابی |
| :---: | :--- | :--- | :--- |
| **۱** | کل رکوردهای بازیابی‌شده از پایگاه‌ها (Total Retrieved) | **۴۳ رکورد منحصر‌به‌فرد** | E-Utilities PubMed API + Europe PMC REST API |
| **۲** | رکوردهای تکراری حذف‌شده (Deduplication) | **۲ رکورد** | تطابق DOI و PMID دوطرفه |
| **۳** | رکوردهای فیلترشده توسط گیت ناسازگاری زیستی | **۱۴ رکورد حذف شد** | حذف مقالات اسپرم دام، واکسیناسیون گله طیور، باروری بوقلمون و علوفه دامی |
| **۴** | رکوردهای مردود در گیت مرتبط‌بودن زمینه‌ای (Relevance Gate) | **۲ رکورد** | ارزیابی ابعاد ۱۰‌گانه Contextual Relevance |
| **۵** | رکوردهای واجد شرایط غربالگری (Screening Pool) | **۲۷ رکورد معتبر با چکیده کامل XML** | اعتبارسنجی کامل متن چکیده و نویسندگان از E-Fetch |
| **۶** | رفرنس‌های نهایی انتخاب‌شده برای پروپوزال (Selected Portfolio) | **دقیقاً ۲۵ رفرنس** | سقف قطعی $\le 25$ و کف $\ge 15$ بدون ورم مصنوعی |
| **۷** | مقالات با ارتباط مستقیم (DIRECT Evidence) | **۳ مقاله** | انکولیز مستقیم NDV در سلول‌های A549 (PMIDs: 33968198, 41170972, 41942850) |
| **۸** | مقالات آنالوگ نزدیک (CLOSE_ANALOG Evidence) | **۱۴ مقاله** | مشتقات C-3 لوپئول، عصاره‌های تری‌ترپنی، ویروس‌های rVSV-NDV در ریه |
| **۹** | مقالات پشتیبان مکانیسمی (MECHANISTIC_SUPPORT) | **۴ مقاله** | مسیرهای کاسپاز، Bax/Bcl-2، اینترفرون و سیگنالینگ Akt/MAPK |
| **۱۰** | مقالات متدولوژیک و استانداردها (METHOD_SUPPORT) | **۳ مقاله** | الگوریتم چو-تالاتای (1984, 2006) و آزمون MTT مسمن (1983) |
| **۱۱** | مقالات غیرمستقیم ویروس‌شناسی (INDIRECT) | **۱ مقاله** | برهم‌کنش گلیکوپروتئین‌های فیوژن پارامیکسو ویروس‌ها (PMID: 39792924) |
| **۱۲** | وضعیت شواهد هم‌افزایی (Synergy Evidence Status) | **۰ مستقیم / ۲ آنالوگ فیتوکمیکال / ۲۰ مونوتراپی / ۳ متد** | مهار خطای Monotherapy Synergy Fallacy |
| **۱۳** | نتیجه ممیزی شکاف جستجو (Search Gap Audit Verdict) | **NO_DIRECT_STUDY_IDENTIFIED** | اجرای ۸ کوئری ترکیبی در PubMed و Europe PMC |
| **۱۴** | نتیجه ممیزی ادعاها و استنادات (Claim Entailment Audit) | **۱۴ از ۱۴ ادعا پذیرفته شد (100% Entailed)** | صفر ادعای کاذب یا فراتر از شواهد تجربی (Zero Overclaims) |

## 3. ترکیب هویتی ترکیبات و پلتفرم‌های زیستی (Gate Identity Composition)

### الف) طبقه‌بندی ماده مداخله (Compound Identity Gate)
- **PARENT_COMPOUND:** ۴ مقاله (لوپئول خالص در مطالعات مهار تهاجم و استانداردهای روش‌شناسی)
- **COMPOUND_DERIVATIVE:** ۴ مقاله (مشتقات فسفونیوم کواترنری، کربامات‌های C-3 و کونژوگه‌های تیازولیدین‌دیون لوپئول)
- **COMPOUND_ANALOG:** ۱ مقاله (بررسی مقایسه‌ای ۶ تری‌ترپن پنج‌حلقه‌ای)
- **CONTAINING_EXTRACT:** ۳ مقاله (عصاره‌های تام غنی از لوپئول و تری‌ترپنوئیدها)
- **NOT_APPLICABLE / BIOLOGICAL:** ۱۳ مقاله (ویروس نیوکاسل و کنترل‌های کموتراپی)

### ب) طبقه‌بندی پلتفرم ویروسی (Viral Platform Gate)
- **WILD_TYPE_OR_STANDARD_ONCOLYTIC_NDV:** ۳ مقاله (سویه‌های استاندارد انکولیتیک NDV در A549)
- **CHIMERIC_OR_RECOMBINANT_PLATFORM:** ۳ مقاله (پلتفرم‌های rVSV-NDV، IL-12 oNDV و NDV-anti-VEGFR2)
- **NOT_APPLICABLE:** ۱۹ مقاله (مطالعات صرفاً شیمیایی یا متدولوژیک)
